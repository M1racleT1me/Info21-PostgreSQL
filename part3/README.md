# part3 — Функции и аналитика

## Что внутри
- `part3.sql` — набор PL/pgSQL процедур и функций:
  - `read_TransferredPoints()` — возвращает таблицу TransferredPoints в более человекочитаемом виде: ник пира 1, ник пира 2, количество переданных пир-поинтов.
  - `read_XP()` — возвращает таблицу: ник пользователя, название проверенного задания, количество полученного XP (только успешные проверки).
  - `peers_not_exited(day_visit date)` — возвращает список пиров, которые не выходили из кампуса в указанный день.
  - `change_prp_peers()` — считает изменение количества пир-поинтов каждого пира по таблице TransferredPoints.
  - `change_number_prp()` — считает изменение количества пир-поинтов по таблице, возвращаемой функцией read_TransferredPoints().
  - `frequently_checked_task_for_days()` — определяет самое часто проверяемое задание за каждый день.
  - `peers_finished_blocks(block_name VARCHAR)` — возвращает всех пиров, выполнивших указанный блок задач, и дату завершения последнего задания.
  - `every_student_should_be_tested()` — определяет, к какому пиру стоит идти на проверку каждому студенту, исходя из рекомендаций друзей.
  - `pr_peer_blocks_simple(first_block, second_block)` — вычисляет процент пиров, которые приступили только к блоку 1, только к блоку 2, к обоим или ни к одному.
  - `peers_was_checked_on_birthday()` — возвращает процент пиров, которые успешно или неуспешно проходили проверку в свой день рождения.
  - `find_peers_completed_tasks_except(first_task, second_task, third_task)` — возвращает пиров, которые сдали первые два задания, но не сдали третье.
  - `number_previous_tasks_for_future()` — показывает для каждой задачи количество предшествующих заданий (рекурсивное вычисление зависимостей).
  - `lucky_days(n)` — определяет дни с хотя бы N подряд успешными проверками с достаточным количеством XP.
  - `get_top_peer()` — возвращает пира с наибольшим количеством XP.
  - `find_early_coming_peers(find_time, N)` — пиры, приходившие раньше заданного времени не менее N раз.
  - `find_left_peers(N, M)` — пиры, выходившие из кампуса больше M раз за последние N дней.
  - `percentage_entrance_each_month()` — процент ранних входов в кампус по месяцам рождения.
