# part2 — Процедуры и триггеры (логика изменения данных)

## Что внутри
- `part2.sql` — набор PL/pgSQL процедур и триггеров:
  - `prd_add_p2p_check` — процедура добавления P2P-проверки (создаёт запись, обновляет `TransferredPoints` и т.п.).
  - `prd_add_verter_check` — процедура добавления проверки типа Verter.
  - `check_p2p_insert` - триггер для обновления `TransferredPoints` при вставке в таблицу P2P.
  - `check_xp_insert` - триггер на проверку валидации вставки в `XP` (проверка корректности данных).
