# Info21 — Data analysis and statistics (PostgreSQL)

Учебный проект, реализующий полную базу данных и аналитическую систему для School 21:
- создание и наполнение базы данных, импорт/экспорт данных CSV;
- процедуры и триггеры для проверки и изменения данных;
- аналитические функции и оконные запросы;

## Стек технологий
PostgreSQL 17, SQL (DDL/DML), PL/pgSQL, оконные функции, агрегатные функции, триггеры, процедуры, CTE.

## Структура репозитория
- `dataset_sql/` — (опционально) исходные CSV-файлы, если ты их добавишь.
- `part1/`
  - `part1.sql` — создание схемы (таблицы, типы, ограничения).  
  - `part1_insert.sql` — пример заполнения (примерные данные).  
  - `import.sql` / `export.sql` — процедуры для импорта/экспорта CSV.
- `part2/`
  - `part2.sql` — процедуры и триггеры для изменения данных.
- `part3/`
  - `part3.sql` — аналитические функции и процедуры (отчёты, агрегаты).
- `README.md` — информация о проекте.  
- `task.md` — условие задания (описание таблиц, требований и набор задач).
