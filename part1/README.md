# part1 — Схема и импорт/экспорт

## Что внутри
- `part1.sql` — создание таблиц и ограничений (основная схема).
- `part1_insert.sql` — примерные INSERT-запросы (демо-данные).
- `import.sql` — скрипт/процедура для импорта данных из CSV; содержит установку переменной пути к датасету.
- `export.sql` — скрипт/процедура для экспорта данных в CSV; содержит установку переменной пути к датасету.

## Что делает
- Создаёт основные таблицы (Peers, Tasks, P2P, Verter, Checks, TransferredPoints, Friends, Recommendations, XP, TimeTracking).
- Предусмотрен импорт/экспорт CSV для быстрой загрузки/выгрузки данных.
- `part1_insert.sql` — набор тестовых записей для быстрой проверки логики в следующих частях.
